# Project technology logos

Retrieved on 2026-11-18. Assets are served locally and rendered in black on light
surfaces and white on dark surfaces.

- Simple Icons supplies Go, Flutter, OpenSearch, Kubernetes, Next.js, Spring,
  Spring Boot, Hibernate, Jenkins, Angular, Svelte, TypeScript, Tailwind CSS,
  Kotlin, Swift, Jetpack Compose, and Supabase. SVGs are from
  `https://raw.githubusercontent.com/simple-icons/simple-icons/develop/icons/`.
  Simple Icons assets use CC0. Brand names and marks belong to their owners.
  Kotlin, Swift, and Svelte marks represent Kotlin Multiplatform, SwiftUI, and
  SvelteKit respectively.
- Echo uses the symbol from the official light logo. The wordmark group was removed
  and its viewBox fitted to the symbol.
  https://raw.githubusercontent.com/labstack/echo/master/.github/assets/echo-logo-light.svg
- NGXS uses its official SVG wordmark.
  https://raw.githubusercontent.com/ngxs/store/master/docs/assets/ngxs-horizontal.svg
- NG-ZORRO uses its official mark.
  https://ng.ant.design/assets/img/logo.svg

SQL, CI/CD, and Provider use Lucide database, workflow, and package symbols.
