# Maple Mono

Official release: https://github.com/subframe7536/maple-font/releases/tag/v7.9
Archive: `MapleMono-Woff2.zip` (unmodified regular, medium and bold WOFF2 files).
The archive SHA-256 was checked against the release checksum before extraction.

License: SIL Open Font License 1.1, included in
`static/assets/fonts/MapleMono-LICENSE.txt` and shipped with the website.

CSS uses local bundled assets through Vite, so fonts work offline, in private
PDF exports, and under the GitHub Pages base path without a third-party CDN.
